# The packages the app imports, pinned. The Dockerfile installs requirements.lock,
# not this file: every deploy rebuilds the image on the box, so an unpinned
# dependency means a merge can ship a different library than the one tested.
# pydantic-ai moves fast, and tg_model.pkl was pickled by scikit-learn 1.9.1 --
# a newer scikit-learn may refuse the pickle, and the designer then quietly
# falls back to the handbook table.
#
# To upgrade: change a pin here, then regenerate the lock inside the same image
# the server builds from:
#   docker run --rm -v "$PWD":/w -w /w python:3.13-slim sh -c \
#     "pip install -q -r requirements.txt && pip freeze > requirements.lock"
